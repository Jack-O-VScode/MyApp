    Sync across devices

    Sync uses a free Supabase project that belongs to you — your events and notes stay in your own database, not on anyone else's server.

    Where do I find these? (one-time setup)
    1. Create a free account at supabase.com and start a new project.
    2. Open SQL Editor, paste the block below and run it.
    3. Open Project Settings → API and copy the Project URL and the anon public key into the boxes above.
    4. Do the same on your other device, then sign in with the same email on both.
    Run this once in the SQL Editor 
    create table if not exists public.sync_records (
  user_id    uuid not null references auth.users(id) on delete cascade,
  id         text not null,
  kind       text not null,
  payload    jsonb not null default '{}'::jsonb,
  deleted    boolean not null default false,
  created_at bigint not null,
  updated_at bigint not null,
  synced_at  timestamptz not null default now(),
  primary key (user_id, id)
);

alter table public.sync_records enable row level security;

create policy "own rows" on public.sync_records
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);

create index if not exists sync_records_cursor
  on public.sync_records (user_id, synced_at);

create or replace function public.touch_synced_at() returns trigger as $$
begin
  new.synced_at = now();
  return new;
end;
$$ language plpgsql;

create trigger sync_records_touch before insert or update
  on public.sync_records for each row execute function public.touch_synced_at();

    The anon key is meant to be public — row-level security above is what keeps your rows readable only by your own account.

    Use the same email and password on every device. If Supabase emails you a confirmation link when you create the account, click it and then sign in.

    Signed in as

    Changes upload as you make them and download when you open the app or switch back to it. Both devices need the same email.

    Install this app

    iPhone / iPad

    1. Open this page in Safari.
    2. Tap the Share button (square with an arrow).
    3. Choose Add to Home Screen, then Add.

    Windows

    1. Open this page in Edge or Chrome.
    2. Click the install icon in the address bar — or the browser menu → Apps / Cast, save and share → Install this site as an app.
    3. It then opens in its own window and gets a Start-menu entry.

    Your events and notes are stored on the device itself — nothing is uploaded. Use Export backup to move them between devices.
